# AI-EDITABLE: 相机辅助机械臂标零

整理日期：2026-10-27。来源：S031（2026-09-24 起）；S052（2026-10-11 起）。

来源编号对应 [聊天覆盖索引](https://github.com/NullCXX/personal-ai-archive/blob/main/archive/conversations/2026-10-27/index.md)。日期为聊天开始日期；后续修改以同一聊天内较新的明确要求为先。

用户提出使用掌部相机观察关节刻线、提取特征并结合运动控制自动标零；同时比较末端标记/TCP 测量路线。本次范围为手臂子项目，其他身体部位仅作为总体背景。

- 区分关节零偏辨识、TCP 标定与末端误差补偿，避免拿末端补偿仿真当作关节标零完成。
- 先确定机械零位基准、标记所在刚性结构、可观测性、相机内外参及独立验收方法，再扩展多关节流程。
- 当观察臂自身零位也有偏差时，观察姿态不能默认可信；需要参考约束与多姿态证据。
- 单轴闭环、重复性和独立测量应先于全臂自动化；不把尚未确定的精度指标写成实测结果。

历史状态是方案、研发计划和论文调研，相机与设备尚有待到位项。公开摘要不包含单位内部接口、人员分工、具体 OKR 指标或设备接入信息。
