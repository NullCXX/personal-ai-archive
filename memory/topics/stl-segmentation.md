# AI-EDITABLE: STL 语义与实体拆件经验

整理日期：2026-10-27。来源：S002（2026-08-17 起）；S005（2026-08-25 起）；S006（2026-08-28 起）；S012（2026-09-13 起）。

来源编号对应 [聊天覆盖索引](https://github.com/NullCXX/personal-ai-archive/blob/main/archive/conversations/2026-10-27/index.md)。日期为聊天开始日期；后续修改以同一聊天内较新的明确要求为先。

目标是“自然完整的光头人物＋独立闭合头发”，保留脸、五官和耳朵；不是仅给三角面着色，也不是导出开口薄壳。

- 维持既有 Electron + Three.js 架构与真实第一阶段输出，复用实际数据，不另造演示工程。
- 人工标注、自动摆放、训练预处理和渲染必须统一到 canonical source mesh space。Face-ID、三角面顺序、哈希与变换矩阵需要明确映射；先通过 oracle replay，再讨论自动学习能力。
- 区分 oracle replay、人工辅助和 blind inference，不能用偷偷读取人工答案来证明泛化成功。
- 完整头发内部子标签的分歧不等于目标与剩余模型的边界冲突；先聚合用户要求保持整体的目标组。
- 切缝需检查真实边界证据、非平面形状和闭合性；二维投影包含不能单独决定三维孔洞关系。
- fan-artifact guard 拦截后应排查三角化、缝合与表面折叠，不降低阈值强行导出。

最近可见的详细反馈仍报告头皮曲面折叠/穿透。历史 AI 报告过局部三角面质量改善，但这不代表整体拆件达标；后续应从真实失败回放和多视角结果继续。

补充来源 V022：用户反馈多视角识别卡住，历史助手报告加入异步让步和阶段进度。界面响应、算法指标与最终闭合效果应分别验收，不能因一次性能修复就宣布拆件目标完成。
