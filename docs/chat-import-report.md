## 证据与隐私处理

- 本人明确陈述可进入个人事实/偏好；学习问题不等于已经掌握，文稿中的功能宣传不等于通过工程验收。
- AI 历史“完成”回复按历史报告标记，本次没有重新运行所有旧工程或复验设备。
- 公司登记、软著提交/受理、最终 Logo 与名称、部分 AI 角色创建等缺乏完成证据，均保留为未确认。
- 私人生活和关系话题仅保留中性覆盖条目；密钥、密码、账号、联系方式、真实姓名、第三方身份、个人二维码、网络参数和内部财务/接口不进入公开摘要。
- 公开前检查了已有 Git 历史的 50 个内容对象，未命中凭据或手机号特征；本次拟提交内容另做扫描、来源编号和文件一致性检查。
- 日期使用 Asia/Shanghai；来源页上的日期为聊天创建日期，不把跨月追加内容误当成同一天发生。

## 验收与使用

本地 16 项工具测试通过，包括新增的匿名读取初始化和无凭据写入拒绝测试；Markdown 校验通过。变更通过独立分支与 PR 发布，在线最终结果以 [Actions](https://github.com/NullCXX/personal-ai-archive/actions) 和对应 PR 的 archive-validate 检查为准。

AI 开始任务时读取 [AGENTS.md](../AGENTS.md)、[个人信息](../identity/profile.md) 和 [工作偏好](../workflow/preferences.md)，再按需读取 [来源索引](../archive/conversations/2026-10-27/index.md) 及项目主题。公开 URL 可供具备浏览能力的 AI 使用，写入仍需要授权工具，不能承诺所有平台已经自动连接。

本地另外提供来源编号与本机会话的映射、更新后的仓库 ZIP 和 Git 历史备份；来源映射不发布到公共仓库。
